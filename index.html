02

PERSONAL PROJECT · UNITY / VRCHAT PIPELINE

VRChat Room & Avatar Pipeline

개인 VRChat 월드와 아바타 제작을 목표로 Blender → FBX → Unity → VRChat으로 이어지는 실시간 3D 제작 파이프라인을 구성 및 기록하는 개인 학습 프로젝트

진행 기간
2026 · 진행 중
참여 형태
개인 · VRChat 월드/아바타 제작 파이프라인 학습

현재 진행 상태

  • VRChat Creator Companion(VCC)으로 World 프로젝트 구성
  • Unity Primitive를 이용한 Room Prototype 제작
  • Floor 및 Wall Collider 설정과 World Spawn 구성
  • VRChat SDK World Validation 통과 및 Build 성공
  • 3D Prop인 Desk_v01.fbx를 Assets/Models/Props에 추가

Repository

실제 Unity 프로젝트의 Scene, FBX 모델, Packages, ProjectSettings와 진행 기록을 GitHub에서 관리하고 있습니다.

목표

VRChat 개인 월드와 기본 아바타를 직접 제작하면서 Blender에서 만든 3D 리소스를 FBX로 내보내고, Unity에 임포트한 뒤 VRChat SDK를 통해 검증·빌드하는 전체 흐름을 익히는 것.

현재 저장소의 상황

Assets/Scenes/VRCDefaultWorldScene.unity에는 Floor, 네 방향 Wall, Collider와 VRCWorld Spawn 설정, Assets/Models/Props/Desk_v01.fbx를 통해 외부 3D Asset을 프로젝트에 추가하는 흐름
