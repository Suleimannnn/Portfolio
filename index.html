01

TEAM PROJECT · UI / INTERACTION DESIGN

Mobile Game UI & GPS Interaction

PC 환경을 기준으로 설계된 게임 시연을 모바일 환경에 맞게 재구성하고, GPS 기반 플레이를 고려해 화면 정보와 인터랙션 우선순위를 정리한 프로젝트 예시입니다.

진행 기간
2026 · 진행 중
참여 형태
팀 프로젝트 · UI 구조 및 모바일 인터랙션 설계

내가 맡은 일

  • PC 기반 조작 흐름을 모바일 사용 환경에 맞게 재구성
  • GPS 기반 이동을 고려해 화면에 필요한 정보와 행동 버튼의 우선순위 정리
  • Figma 기반 모바일 UI 러프 및 화면 구조 설계

확인할 수 있는 결과

이동 조작과 화면 버튼의 역할이 겹치지 않도록 기능을 나누고, 한 손 사용과 작은 화면을 고려해 주요 행동 영역을 화면 하단에 모으는 방향으로 정리했습니다.

  • Figma
  • HTML/CSS
  • GitHub
만든 과정과 해결한 문제

무엇을 만들려고 했나

PC용 시연 화면을 단순 축소하지 않고, 모바일의 입력 방식과 이동 환경을 고려한 별도의 UI 흐름을 설계하는 것을 목표로 했습니다.

어디에서 막혔고, 어떻게 풀었나

WASD 입력을 그대로 옮기면 화면을 차지하는 가상 조이스틱이 필요해집니다. 이를 GPS 기반 이동으로 대체하는 방향을 검토하고, 조작 버튼보다 위치 상태와 행동 선택을 더 중요하게 보이도록 정보 구조를 바꿨습니다.

어떻게 확인했고, 무엇이 남았나

작은 화면에서 텍스트와 버튼이 겹치지 않는지 확인하고 있습니다. 다음 단계에서는 실제 플레이 테스트를 통해 버튼 크기와 정보량을 조정할 계획입니다.

02

PERSONAL STUDY · PYTHON TOOL

Python Asset Validator

3D 프로젝트의 리소스 파일을 관리한다는 상황을 가정하고, 파일 이름과 확장자의 기본 규칙을 자동 검사하는 Python 학습 도구입니다.

진행 기간
2026 · 개인 학습
참여 형태
개인 · Python 파일 처리 및 검증 로직 구현

내가 맡은 일

  • pathlib를 이용해 파일 경로·이름·확장자 정보 처리
  • 대문자 확장자와 파일명 공백을 검사하는 규칙 구현
  • 확장자별 개수를 집계하고 여러 폴더의 결과를 합산
  • 반복 기능을 함수로 분리하고 타입 힌트를 적용

확인할 수 있는 결과

파일마다 검사 결과를 출력하고 폴더 전체의 확장자 분포를 집계합니다. 학습 단계의 도구이지만 이후 실제 3D 리소스 네이밍 규칙과 폴더 구조 검사로 확장할 수 있습니다.

  • Python
  • pathlib
  • Git
  • GitHub
만든 과정과 해결한 문제

무엇을 만들려고 했나

모델·이미지·오디오 파일이 섞여 있는 폴더를 빠르게 확인할 수 있는 작은 검사 도구를 만들면서 Python 파일 처리를 익히는 것이 목표였습니다.

어디에서 막혔고, 어떻게 풀었나

처음에는 문자열을 직접 나누어 확장자를 찾았지만 예외 처리가 불편했습니다. pathlib의 Path 객체와 suffix를 사용하도록 바꾸고, 검사·집계 기능을 각각 함수로 분리해 코드를 단순화했습니다.

어떻게 확인했고, 무엇이 남았나

대문자 확장자, 공백이 포함된 이름, 정상 파일을 섞어 결과를 확인했습니다. 이후 용량 제한, 네이밍 규칙, 폴더 구조 검사 기능을 추가할 수 있습니다.
